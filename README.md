BituachBot — AI-Powered Insurance Assistant

An AI-assisted insurance management platform for Israeli insurance agents and their clients.

Live Application

Overview

BituachBot is a web-based insurance assistance platform designed to help insurance agents organize policy information, onboard clients, manage documents, and provide more accessible policy support.

The project was developed using Claude Code, connected to a GitHub repository, through an iterative AI-assisted development workflow.

The Problem

Insurance agents manage large volumes of policy documents, customer inquiries, and administrative tasks. Clients often struggle to locate relevant policy information and understand their coverage.

BituachBot explores how AI-assisted tools and automation can simplify these workflows.

Development with Claude Code

My responsibilities included:

Identifying the business problem and defining product requirements.

Translating requirements into natural-language development instructions.

Directing Claude Code to implement features and modify repository files.

Testing application behavior and identifying issues.

Iteratively improving the user interface and functionality.

Coordinating deployment and ongoing refinements.

Claude Code generated and modified application code while I directed the product requirements, development priorities, and functional testing.

Project Status

BituachBot is deployed as a Streamlit web application. Its current interfaces include separate experiences for insurance agents and clients.

Some capabilities and integrations remain subject to functional validation before broader use.
